# Praktik Machine Learning dengan Python

Repository ini berisi praktik materi Bab 2 dan Bab 3 dari buku *Introduction to Machine Learning with Python*.

## Isi Repository

- `bab-2-supervised-learning/`: klasifikasi, regresi, KNN, Naive Bayes, Decision Tree, evaluasi, dan overfitting.
- `bab-3-unsupervised-learning/`: preprocessing, scaling, PCA, K-Means, Agglomerative Clustering, dan DBSCAN.

Notebook dapat dibuka dan dijalankan menggunakan Google Colab.

## Cara Membuka di Google Colab

1. Buka https://colab.research.google.com/
2. Pilih menu **File → Upload notebook**.
3. Pilih file `.ipynb` dari folder repository.
4. Jalankan setiap sel secara berurutan.

## Catatan

Kode ditulis sebagai praktik mandiri berdasarkan topik pembelajaran, bukan salinan penuh dari kode buku.
