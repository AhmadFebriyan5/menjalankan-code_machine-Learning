# Praktik Machine Learning dengan Python

Disini ini membahas praktik materi Bab 2 dan Bab 3 dari buku *Introduction to Machine Learning with Python*.

## Isi Repository

- `bab-2-supervised-learning/`: klasifikasi, regresi, KNN, Naive Bayes, Decision Tree, evaluasi, dan overfitting.
- `bab-3-unsupervised-learning/`: preprocessing, scaling, PCA, K-Means, Agglomerative Clustering, dan DBSCAN.
